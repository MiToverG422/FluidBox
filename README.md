## 说明

FluidBox 是一个通过 ChatGPT-Codex 辅助开发的 ColorOS 系统优化/扩展模块。
使用模型：GPT5.5

！！！项目按个人喜好制作，不喜欢可以不用，不接受无意义争论！！！

## 测试机型

- OPPO Find X9 Ultra / ColorOS 16.0.9.402

## 是否支援OxygenOS/RealmeUI？

- 不会主动适配，因为他们即将被ColorOS取代
